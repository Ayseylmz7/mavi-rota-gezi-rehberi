# 🌍 Mavi Rota | Gezi Rehberi Web Uygulaması

Bu depo, **Web Programlama** dersleri kapsamında HTML5 ve harici CSS3 kullanılarak sıfırdan geliştirilmiş, modern ve duyarlı bir seyahat/gezi rehberi web sitesini içermektedir.

## 🚀 Proje Hakkında
Proje; kullanıcıların popüler doğa, sahil ve kültür rotalarını inceleyebileceği, seyahat hazırlık listelerini ve karşılaştırma tablolarını görüntüleyebileceği zengin bir arayüze sahiptir.

### 🛠️ Kullanılan Teknolojiler ve Özellikler
* **HTML5:** Anlamsal etiketler (`<header>`, `<main>`, `<article>`, `<aside>`, `<footer>`), resim etiketleri (`<figure>`, `<figcaption>`), hazırlık listeleri (`<ol>`, `<ul>`) ve yapılandırılmış veri tabloları.
* **Harici CSS3 (`style.css`):** 
  * Özel 12'li kolon yapısına sahip esnek grid sistemi (Flexbox/Float altyapısı).
  * Mobil uyumlu tasarım (`@media query` ile küçük ekranlarda tek sütuna geçiş).
  * Şık renk paleti, hover efektleri ve özel başlık çizgileri.
